- **Timeline**: 15 minutes elapsed from first gallery preview inspection and brand domain provisioning to receiving the verified signed delivery receipt.
- **Bottleneck**: Waiting for the shared new-account sending capacity window (`signup_sending_capacity_reached`) to reset at the top of the hour (`retry_at`), which required polling the timestamp and retrying `nitro_send_message` with `template_id: 27653` and the same `idempotency_key`.
- **Feature Recommendation**: Add an automatic deferred retry queue for `proof@dogfood.nitrosend.net` verification sends when new accounts encounter the shared signup sending allowance limit, eliminating manual retry polling during initial MCP setup.
